# 开发状态 · 2026-10-24

## 已实现

- 独立本地Git仓库、零npm运行依赖服务、安装自检；旧节目、权重和本机配置未进入仓库。
- 录音复制导入、元数据探测、SHA绑定、整数时间JSON转录导入。
- 同一份结构化方案供模型API、手动编辑、CLI和外部代理使用。
- Chat Completions兼容API、三种JSON模式、分段理解与主线、逐句决定、全文模型复核。
- 本地严格校验每步响应；拒绝未知编号、额外字段与锁定项修改。失败诊断、成功检查点保留、用户主动重试与取消。
- 短回应和仍与保留音频重叠的拟删句自动保守恢复，原模型决定单独留痕。
- 方案批准、历史恢复、源时间映射、整句粗剪、单轨PCM24 WAV/MP3导出。
- 多轨共用时间线、独立分轨导出、逐轨审听、同位置切换。
- 批注绑定渲染版本、具体WAV、音频SHA和原始源区间；局部或全文意见返修。未绑定具体音轨的旧批注须手动核对。
- 切换API地址时清除内存中的旧密钥，离线音频子进程不接收模型密钥。

## 工程验证

29项自动测试通过，运行真实本机HTTP、本机模拟模型服务及FFmpeg/Python，使用合成信号与随仓库提供的公有领域短语音。包括单/多轨剪辑、完整独立解码、保留样本位置和增益、源文件不变、版本冲突、锁定保护、SHA变化拒绝、取消任务、短回应及重叠恢复、逐轨批注和产物校验和。另验证了客户端中断音频读取、清单内文件缺失时服务仍可用，避免快速切换音轨导致服务退出。

模拟长稿复核连续返回未知编号、额外字段、违反锁定项三类错误：均拒绝应用、保留诊断；5个成功步骤复用，只有用户主动重试的复核步骤再次调用。模拟单轨不合规响应也验证了脱敏诊断、原方案不变及显式重试。

局部返修或手动修改后，此前全文复核会标为旧方案结果，不能沿用为当前方案已复核的证明。

本机 `npm run doctor` 与语法检查通过。另创建了全新Python3.12虚拟环境，按分发文件哈希安装锁定依赖，未复用生产环境site-packages；自检与29项测试通过。仅代表同一台macOS电脑上的干净Python环境，不等于其他电脑、操作系统和本地转录模型推理均已验收。

自检检查Node、Python3.12虚拟环境、可导入依赖、FFmpeg/FFprobe、MP3编码器、可选离线模型文件与数据目录写入。它不下载模型，不请求模型API。首次加载新安装的转录依赖曾超过20秒，已将自检超时改为60秒并明确报告加载超时。

浏览器用新的双轨合成工程验证了选择第二轨、保存批注、回到原音轨与时间、切换到第一轨保留0.5秒位置。播放器能够载入4.42秒候选；这不是人声听感验证。

## 私有真实样本

连续25分17秒既有转录：135句，DeepSeek真实调用7次，输入26670 token、输出8311 token。原模型拟删28句；短回应保护恢复10句，推荐删18句。用户批准后已导出23分22.340秒粗剪，检查了时间映射、保留样本、校验和和完整解码。用户给出“还可以我觉得”的初步反馈，但未说明实际听完的范围，不能作为全段听感验收。

随后扩大到94分钟的测试已停止。一次全文模型复核返回无效决定，整份结果未应用，未批准或渲染整期音频。旧错误缺少字段级诊断，不能反推具体原因。本轮诊断与恢复改进只通过模拟响应验证，没有再次调用真实整期API，也没有改动节目音频。

私人音频、稿件、方案、检查点、截图和本机配置只在Git忽略目录中。

## 当前边界

- 自动方案保持原顺序；可手动移句，复杂移动仍需语义和听感核对。
- 本地转录入口已实现；已对公开12秒小样完成本地模型推理，但未完成整期录音和听辨验收。转录与渲染中断需重跑该任务。
- 多轨须手动声明共同时间轴、导入带trackId转录；没有自动漂移校正、自动选麦或混音。当前交付是可继续处理的同步分轨粗剪。
- 全文复核是模型内容检查，不是音频听辨；输入超过上限时明确标记跳过。整期内容质量仍未完成验证。
- 整句边界采用保守扩边，尚未完成词音节级切点验证；没有整期ASR复核、降噪或母带响度验收。输出始终标为审阅候选。
- 模型失败不自动收费重试；尚无金额预算上限。诊断可能包含访谈内容，不应公开。
- 首版为 `0.1.0-alpha.1` 实验版；跨平台实际体验、长音频与复杂剪辑质量仍需持续验证。
